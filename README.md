# 十四亿分之一

> 你会出生在哪里？来过一次另一个人的一生。

**在线试玩：** https://wangchong8068-dot.github.io/1in1.4b/

一个网页小游戏。按全国真实的出生比例，随机把你“生”在中国的某个省份、某种出生地（城市、县镇、乡村或山区乡村），然后一年一年过完这一生：上学、高考、打工、成家、养老。结局会拿这一生和你所在城市的同龄人做对比，并生成一张可以分享的人生卡片。

## 致敬

本作的玩法学习自 **Jin's Earth** 的网页游戏 [《80亿分之1》](http://1in8b.life)。原作把视角放在全世界，本作把它缩小到中国，想让玩家体会和自己同一秒出生、命运却完全不同的另一个人。谢谢原作者。

## 数据

各省人口、出生率、城镇化率、人均可支配收入来自国家统计局 2024 年数据，预期寿命来自第七次全国人口普查，婴儿和 5 岁以下死亡率来自国家卫健委统计公报。部分参数是估算值，例如各省山区人口比例、升学概率、留守概率，游戏只用来引发思考，不代表精确的统计结论。

## 运行

纯 HTML + JavaScript，没有依赖。克隆后直接用浏览器打开 `index.html` 即可。
